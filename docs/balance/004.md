# Balance snapshot 004 — R-035, and a solver bug that faked a regression

1000 runs, `npm run sim -- --runs 1000`. Supersedes `003.md`.

The headline is not R-035. It is that **every sweep taken between R-029 and this
snapshot was measuring a broken bot**, and read as the game having become twice
as hard.

## The false regression

A sweep taken while building R-035 reported a 20.9% win rate against 003's
43.7%, and a 44.1% Act I death rate against 10.4%. Bisecting the merges found it
arrived whole with PR #7 (R-029, Silent Start):

| merge | win rate | act I deaths |
|---|---|---|
| #6 `2f3f2d0` | 42.7% | 9.8% |
| #7 `3053be2` | **21.7%** | **44.7%** |
| #8 `26e9393` | 21.7% | 44.7% |
| #9 `a4350e7` | 21.7% | 44.7% |

R-029 changed Silent Start's suppression from reporting `GREY` in place of
`YELLOW` to reporting `UNKNOWN`. The solver's consistency check had exactly one
reading of `UNKNOWN` — "a GREEN that Decay faded" — so on the first guess of
every Silent Start word it required that position to be green in the candidate,
eliminated the true answer, and then burned the pool failing to solve a word it
had already ruled out. Silent Start is an Act I modifier, which is why the
damage landed almost entirely in Act I.

Two stale readings, both fixed:

- `UNKNOWN` on a Silent Start row means the true state is **YELLOW**. It is the
  strongest constraint on the row, not the weakest.
- `GREY` on a Silent Start row is now an **ordinary grey** — genuinely absent, a
  full constraint. The old "not green here, nothing more" was correct only while
  suppression was lying.

Filed as §13 I-27. The lesson is cheap to state and was expensive to find: a
rules change that alters which feedback states the engine can emit must be
mirrored in the solver, or the next sweep reports the game when it is describing
the bot.

## §10.3 targets

| metric | 003 | now | target | |
|---|---|---|---|---|
| win rate | 43.7% | **45.1%** | 25–35% | OFF |
| act I death rate | 10.4% | **6.6%** | <15% | OK |
| word-luck deaths | 33.7% | **29.3%** | <5% of deaths | OFF — §13 I-25 |
| mean emergency purchases | 0.82 | **0.84** | >0 | marginal |

Both headline numbers moved the *right* way against 003, and for a reason rather
than by luck: R-029's honest `UNKNOWN` carries more information than the lying
`GREY` it replaced, so a correct reading of it makes the game easier than 003
measured. 003's numbers were taken before R-029 and are still sound as a
before-picture; everything measured between R-029 and here should be discarded.

## What R-035 itself cost

Measured against the same build with the change stashed, both sweeps still
carrying the solver bug, so the delta is like-for-like:

| | without R-035 | with R-035 |
|---|---|---|
| win rate | 21.7% | 20.9% |

About one point, in the expected direction: a forge that offers three relics
instead of every relic you hold is a weaker forge. At a mean of **7.2 eligible
relics held** across 203 walked forges, the cap binds on **79%** of visits, so
the node went from a formality to a choice for the price of a point.
