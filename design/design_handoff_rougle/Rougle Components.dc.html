No springs, no bounce, no fade-in-on-scroll, no opacity hover. Step easing is reserved for anything that should feel mechanical — reveals, drains, stamps; cubic-bezier(0.2, 0.8, 0.2, 1) for anything that travels. Every duration is ≤620ms so a fast player is never waiting on the interface. prefers-reduced-motion maps to the reducedMotion prop: all durations collapse to 1ms, loops stop, state still changes.

§07

TOKEN CONTRACT

NIKOLASS + THE GAME LAYER
INHERITED · NIKOLASSDO NOT REDEFINE

The game loads tokens/{fonts,colors,typography,spacing,motion,base}.css and pins data-theme="dark" on the root — permanently, not as a toggle. Everything structural comes from the system: the --dark-* paper ramp, the --term-* terminal palette, --magenta and --kelly for rarity, and the motion and spacing scales.

WHY A GAME LAYER EXISTS11 TOKENS

NIKOLASS's dark ramp has four steps — enough for a document, not for a HUD that must stack chrome over panel over strip over sunken and still separate five tile states. The --g-* layer adds the intermediate steps the game needs and nothing else. It is additive: it never overrides a system token, so a change upstream still reaches the game.
